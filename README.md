# Mini E-Commerce Platform

## Proje Hakkında

Mini E-Commerce Platform, kullanıcıların internet üzerinden ürünleri inceleyebildiği, arama ve filtreleme yapabildiği, ürünleri favorilerine ve sepetlerine ekleyebildiği ve sipariş oluşturabildiği küçük ölçekli bir e-ticaret platformudur.

Proje, bir e-ticaret sisteminin temel çalışma mantığını öğrenmek ve gerçek bir yazılım projesinin geliştirme sürecini deneyimlemek amacıyla geliştirilmektedir.

Proje geliştirme sürecinde frontend, backend, veritabanı, kullanıcı yönetimi, ürün yönetimi, sipariş yönetimi ve temel yönetim işlemleri aşamalı olarak geliştirilecektir.

---

## Projenin Amacı

Projenin temel amacı, sıfırdan başlayarak modern web teknolojilerini kullanarak çalışan bir e-ticaret uygulaması geliştirmektir.

Proje boyunca;

* Web geliştirme temellerinin öğrenilmesi
* React.js ile frontend geliştirme
* Node.js ve Express.js ile backend geliştirme
* PostgreSQL ile veritabanı yönetimi
* REST API geliştirme
* Kullanıcı kimlik doğrulama ve yetkilendirme
* Git ve GitHub kullanımı
* Proje planlama ve versiyon kontrolü
* Hata ayıklama ve test süreçlerinin öğrenilmesi

hedeflenmektedir.

---

## Proje Kapsamı

Platformda üç temel kullanıcı rolü bulunması planlanmaktadır:

### 1. Müşteri

Müşteriler platform üzerinden ürünleri inceleyebilir ve sipariş oluşturabilir.

Temel özellikler:

* Kayıt olma
* Giriş yapma
* Profil bilgilerini görüntüleme
* Adres bilgilerini yönetme
* Ürünleri görüntüleme
* Ürün detaylarını inceleme
* Kategoriye göre ürünleri görüntüleme
* Ürün arama
* Ürünleri filtreleme
* Ürünleri sıralama
* Favorilere ürün ekleme
* Sepete ürün ekleme
* Sepet miktarını değiştirme
* Sipariş oluşturma
* Sipariş geçmişini görüntüleme
* Sipariş durumunu görüntüleme
* Ürünlere puan verme
* Ürünlere yorum yapma

### 2. Satıcı

Satıcılar kendi mağazalarını ve ürünlerini yönetebilir.

Temel özellikler:

* Satıcı hesabı oluşturma
* Giriş yapma
* Mağaza bilgilerini yönetme
* Ürün ekleme
* Ürün güncelleme
* Ürün silme
* Ürün görseli ekleme
* Fiyat belirleme
* Stok miktarını yönetme
* Kategori belirleme
* Gelen siparişleri görüntüleme
* Sipariş durumunu güncelleme
* Temel satış bilgilerini görüntüleme

### 3. Admin

Admin kullanıcıları platformun genel yönetimini gerçekleştirir.

Temel özellikler:

* Kullanıcıları görüntüleme
* Kullanıcı hesaplarını yönetme
* Satıcıları görüntüleme
* Satıcı hesaplarını yönetme
* Ürünleri yönetme
* Kategorileri yönetme
* Siparişleri görüntüleme
* Yorumları kontrol etme
* Ürün ve satıcı onaylarını yönetme
* Hesapları aktif/pasif duruma getirme
* Temel sistem istatistiklerini görüntüleme

## Kullanılacak Teknolojiler

### Frontend

* HTML
* CSS
* JavaScript
* React.js

Frontend tarafında kullanıcıların platform ile etkileşime girebileceği sayfalar ve bileşenler geliştirilecektir.

### Backend

* Node.js
* Express.js

Backend tarafında kullanıcı, ürün, kategori, sepet ve sipariş işlemleri için REST API yapısı oluşturulacaktır.

### Database

* PostgreSQL

Kullanıcı, ürün, kategori, sipariş, favori ve yorum gibi verilerin kalıcı olarak saklanması planlanmaktadır.

### Version Control

* Git
* GitHub

Projenin kaynak kodunun yönetilmesi, değişikliklerin takip edilmesi ve geliştirme sürecinin kayıt altında tutulması için Git ve GitHub kullanılacaktır.

### AI Development Support

* Cursor AI

Cursor AI, geliştirme sürecinde kod yazma, kod açıklama, hata analizi ve öğrenme aşamalarında yardımcı araç olarak kullanılacaktır.

## Proje Geliştirme Yaklaşımı

Proje aşamalı olarak geliştirilecektir.

İlk olarak temel web teknolojileri ve proje yapısı öğrenilecek, daha sonra frontend geliştirilecektir.

Frontend temel seviyede tamamlandıktan sonra React.js kullanılmaya başlanacaktır.

Daha sonra Node.js ve Express.js kullanılarak backend ve REST API yapısı oluşturulacaktır.

Sonraki aşamada PostgreSQL veritabanı sisteme dahil edilerek frontend ve backend ile bağlantısı sağlanacaktır.

Son aşamada kullanıcı yönetimi, sipariş sistemi, yorumlar ve diğer temel özellikler sisteme entegre edilerek test işlemleri gerçekleştirilecektir.
